## Overview

**nbashotpackage** is an R package that is intended for analysis and exploration of shot data from the NBA. Specifically, relating to the locations of shots taken in games and how these have changed over the years. Comparing shot locations from the 2001-2002 season to those in the 2021-2022 season.
